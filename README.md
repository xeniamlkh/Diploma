# Flash Cards Application

## Описание
Приложение по изучению иностранных языков. 
* 	Представляет из себя комлект двусторонних карточек, на одну сторону которой записывается иностранное 
слово, а на другую его перевод и пример.
* 	Пример автоматически подгружается с сервиса Tatoeba.
*   При желании загруженный пример можно заменить на свой.

## Используемые технологии
*	Kotlin
*   KMP: Android, JVM
*   Многомодульное приложение
*   Clean Architecture
*   Jetpack Compose
*   Kotlin Coroutines + Flow
*   Navigation 3
*   MVVM
*   Koin (DI)
*   Room
*   Ktor 
*   Kotlin Serialization
*   Unit tests
*   UI tests
